## Default Permission

Default permissions for snapora plugin

#### This default permission set includes the following:

- `allow-capture`
- `allow-cancel-active`
- `allow-overlay-ready`
- `allow-overlay-prepared`
- `allow-feedback-ready`
- `allow-cancel`
- `allow-report-error`
- `allow-output`
- `allow-confirm`
- `allow-log-message`
- `allow-get-log-path`
