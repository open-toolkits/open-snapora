## Default Permission

Default permissions for snapora plugin

#### This default permission set includes the following:

- `allow-capture`
- `allow-cancel-active`
- `allow-overlay-ready`
- `allow-overlay-prepared`
- `allow-feedback-ready`
- `allow-cancel`
- `allow-report-error`
- `allow-output`
- `allow-confirm`
- `allow-log-message`
- `allow-get-log-path`
- `allow-get-frame-image`
- `allow-prewarm`
- `allow-pinned-ready`
- `allow-pinned-copy`
- `allow-pinned-save`
- `allow-pinned-close`
- `allow-pinned-start-drag`
- `allow-pinned-move-drag`
- `allow-pinned-end-drag`
- `allow-pinned-resize`
